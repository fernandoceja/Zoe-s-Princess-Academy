# Personal work skills

Adapted from *The 7 ChatGPT Work Skills I Use Every Day* for Cursor.

| Skill | Trigger | Notes |
| --- | --- | --- |
| `visualize` | visualize, diagram, chart, what-if | Mermaid, charts, images, canvas |
| `lmk` | LMK / notify me when you're done | Needs `~/.config/lmk/pushover.env` |
| `handoff` | hand off, fresh chat, second opinion | Ready-to-paste context packet |
| `ask` | ask Grok / Gemini | Browser + signed-in session |
| `quick-grill` | grill me | Alignment interview only when asked |
| `skill-builder` | create a skill from my workflow | Interview, then write `SKILL.md` |
| `remotion` | Remotion video / motion graphic | Requires Remotion installed |

These folders are also copied to `~/.cursor/skills/` so they load as personal skills.
